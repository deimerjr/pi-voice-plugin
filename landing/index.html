CORE CAPABILITIES

INGENIERÍA PARA DESARROLLADORES EXIGENTES

Diseñado para trabajar a fondo sin fricción: cero bloqueos de I/O, sin llamadas innecesarias a APIs pagas y con control total del flujo.

01 // LOCAL

KOKORO TTS LOCAL OFFLINE

Servidor local en Python/ONNX administrado por systemd en http://127.0.0.1:8880. Cero costo por token, sin telemetría, latencia ultrabaja y voces naturales en español (Dora, Alex, Santa).

02 // DICTADO

WHISPER STT DIRECTO (ALT+R)

Apretá Alt + R, hablá a tu micrófono y al soltar, Whisper transcribe tu voz al prompt de Pi CLI al instante. Incluye filtro inteligente de silencios y alucinaciones.

03 // SÍNTESIS

MODO AUDIO TL;DR RESUMIDO

¿La IA respondió un reporte de 5 páginas? El modo /voice tldr sintetiza en 1 o 2 frases contundentes el logro principal antes de hablar, ahorrándote minutos de locución innecesaria.

04 // ROBUSTEZ

PIPELINE STREAMING SIN BLOQUEO

Fragmentación inteligente por oraciones: mientras una oración se reproduce por el parlante, la siguiente ya se está sintetizando en paralelo. Cancelación inmediata con AbortController sin crashear.

05 // LIMPIEZA

SANITIZACIÓN DE CÓDIGO Y MARKDOWN

Filtra bloques de código, tablas ASCII, enlaces y etiquetas internas <think> para que el motor lea solo explicaciones fluidas y no caracteres crudos molestos.

06 // UNIVERSAL

SOPORTE MULTI-PROVEEDOR

Intercambiable al vuelo entre Kokoro Local, OpenAI TTS (tts-1/hd), ElevenLabs con clonación de voz o cualquier endpoint REST HTTP custom con una sola instrucción.

CHEAT SHEET

COMANDOS & ATAJOS DE TECLADO

[ AT ] ATAJOS GLOBALES

ATAJO ACCIÓN
Alt + R Iniciar / Detener dictado por micrófono (STT) [MIC]
Alt + S Detener inmediatamente reproducción o dictado [STOP]
Alt + V Abrir menú visual interactivo con soporte de mouse [CFG]
Alt + Up Subir volumen de audio (+10%) [VOL+]
Alt + Down Bajar volumen de audio (-10%) [VOL-]

[ CMD ] COMANDOS /VOICE EN PI

COMANDO DESCRIPCIÓN
/voice menu Abre la interfaz TUI navegable con mouse
/voice crew on|off Alterna el modo conversacional de cuadrilla ("Jefe")
/voice phases on|off Alterna la locución de fases del orquestador
/voice tldr Alterna el resumen ejecutivo breve antes de hablar
/voice on | off Activa o desactiva la lectura automática
/voice provider <t> Cambia a kokoro, openai, elevenlabs
/voice volume <0-150> Ajusta el volumen en porcentaje exacto
