CORE CAPABILITIES

INGENIERÍA PARA DESARROLLADORES EXIGENTES

Diseñado para trabajar a fondo sin fricción: cero bloqueos de I/O, sin llamadas innecesarias a APIs pagas y con control total del flujo.

01 // LOCAL & CLONADO

KOKORO LOCAL & VOCES CLONADAS

Servidor local en Python/ONNX administrado por systemd en http://127.0.0.1:8880. Incluye voces estándar y clones calibrados al 100%: Valeria, Juan Carlos, Fenrir Español, Ximena México, Mateo y Dora Heart.

02 // ANTI-COLISIÓN

CONCURRENCIA MULTI-SESIÓN FIFO

¿Múltiples terminales abiertas a la vez? La cola global inter-proceso evita voces cruzadas: las sesiones esperan su turno ordenadamente. Soporta además modo Interrupción y modo Foco (solo habla la ventana activa).

03 // GRANULARIDAD

TL;DR EN 3 NIVELES (ALTO / MEDIO / BAJO)

Controlá qué tanto se sintetiza la respuesta: Alto (1 sola frase contundente), Medio (2 a 3 frases equilibradas) o Bajo (80-90% de detalle técnico en prosa sin código).

04 // DINÁMICO

CUADRILLA & NOMBRES PERSONALIZABLES

Asigná nombres propios a cada rol de la cuadrilla (Scout, Worker, Reviewer, Orquestador) y definí tu propio apelativo ("Líder", "Jefe", "Comandante") tanto en el menú TUI como por comando CLI.

05 // DICTADO

WHISPER STT CON FILTRO DE SILENCIOS

Apretá Alt + R, hablá al micrófono y soltá: Whisper transcribe tu voz al prompt de Pi CLI al instante. Incluye filtro inteligente para eliminar silencios y alucinaciones de audio vacío.

06 // CONTROL TOTAL

CHEAT SHEET INTEGRADO EN EL MENÚ

Accedé en cualquier momento desde Alt + V a la Guía Completa de Atajos y Controles, con el mapa integral de comandos de consola, navegación de teclado y controles táctiles de mouse.

COMANDOS & ATAJOS DE TECLADO

Referencia rápida para dominar todo el plugin desde la terminal o mediante el menú visual interactivo.

[ AT ] ATAJOS GLOBALES DE TECLADO

ATAJO ACCIÓN
Alt + R Iniciar / Detener dictado por micrófono (STT Whisper) [MIC]
Alt + S Detener inmediatamente reproducción o dictado [STOP]
Alt + V Abrir menú visual interactivo con soporte de mouse [CFG]
Alt + Up Subir volumen de audio (+10%) [VOL+]
Alt + Down Bajar volumen de audio (-10%) [VOL-]

[ CMD ] COMANDOS /VOICE EN PI CLI

COMANDO DESCRIPCIÓN
/voice menu Abre el menú visual interactivo y la Guía Cheat Sheet
/voice read Lee la última respuesta completa palabra por palabra
/voice tldr [alto|medio|bajo] Configura el nivel de detalle de síntesis ejecutiva
/voice crew [on|off] Alterna el modo conversacional de cuadrilla
/voice title [apodo] Configura el tratamiento (Líder, Jefe, Comandante)
/voice name <rol> <nombre> Bautiza a Scout, Worker, Reviewer y Orquestador
/voice concurrency <modo> Coordinación multi-sesión (queue, interrupt, focus)
/voice project [on|off] Antepone el nombre de proyecto ("En [Proyecto]: ...")
/voice tests [on|off] Controla la locución de pruebas de verificación
/voice voice <nombre> Cambia la voz (valeria, juan_carlos, fenrir_es, ximena, mateo, etc.)
/voice volume <0-150> Ajusta el volumen en porcentaje exacto
